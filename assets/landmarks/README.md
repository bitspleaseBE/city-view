# Landmark exterior photos

Street-facing reference photos for named churches and hospitals in Antwerp tiles.
Churches are extruded OSM volumes with pitched roofs, portals, and tower/spire
massing. The landmark photo may dress a thick street-elevation face (not a free
billboard). Heilige Geestkerk: single left square tower + round stair turret
(`neo_romanesque_tower_left`). Hospital photos may dress one street wall. See
`manifest.json` for OSM id / name matching, massing presets, crops, and attribution.
