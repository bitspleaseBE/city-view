# Landmark exterior photos

Reference photos for named churches and hospitals in Antwerp tiles.
Churches are mesh-only: extruded OSM volumes with pitched roofs, portals, tower/
spire massing, and tiling brick/stone/slate materials — **no facade photographs**.
Heilige Geestkerk: single left square tower + round stair turret
(`neo_romanesque_tower_left`). Hospital photos may dress one street wall. See
`manifest.json` for OSM id / name matching, massing presets, crops, and attribution.
