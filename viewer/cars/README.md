# Street cars (Belgian 2025-26 fleet)

Vehicles for runtime traffic (`viewer/traffic.js`) and Blender parked cars
(`blender/cars_blender.py`). Every GLB here is generated by
[`blender/build_car_models.py`](../../blender/build_car_models.py) from published
dimensions (length, width, wheelbase, overhangs, tyre size) and side / front / rear
profiles of real cars. The geometry is original and procedural, with no scanned or
licensed meshes.

| File | Model | Weight |
|------|-------|--------|
| `model_y.glb` | Tesla Model Y (2025 "Juniper") | 12 |
| `bmw_x1.glb` | BMW X1 (U11) | 12 |
| `vw_tiguan.glb` | Volkswagen Tiguan (Mk3) | 9 |
| `peugeot_208.glb` | Peugeot 208 (2024 facelift) | 10 |
| `dacia_sandero.glb` | Dacia Sandero Stepway (2023 facelift) | 10 |
| `kia_ev3.glb` | Kia EV3 | 8 |
| `bmw_5.glb` | BMW 5 Series / i5 (G60) | 8 |
| `model_3.glb` | Tesla Model 3 ("Highland") | 6 |
| `renault_5.glb` | Renault 5 E-Tech | 7 |
| `transit_custom.glb` | Ford Transit Custom (2023-) | 8 |

Weights follow the Belgian new-registration mix: company-car SUVs and EVs, city
hatchbacks, and a share of vans.

GLB conventions (the viewer and parked-car code rely on them):

- Y-up, length on Z, nose toward +Z, wheels resting on y = 0.
- Nodes are `body` plus `wheel-front-left`, `wheel-front-right`, `wheel-back-left` and
  `wheel-back-right`. Each wheel node's origin is on its axle, so `rotation.x` rolls it.
- Materials:
  - `car_paint` is a plain material. The viewer recolours it per car (`CAR_PAINTS` in
    `cars.js`).
  - `car_headlight` and `car_taillight` are swapped for the shared lamp materials, so
    lights glow at night.
  - `car_glass`, `car_trim` and `car_metal` take their colours from vertex colours, which
    keeps each car at six draw calls.
- `fleet.json` sizes are the measured bounds, including mirrors.

Rebuild:

```bash
blender -b --factory-startup -P blender/build_car_models.py                  # all models + fleet.json
blender -b --factory-startup -P blender/build_car_models.py -- --only bmw_x1 # one model
blender -b --factory-startup -P blender/build_car_models.py -- --preview /tmp/cars/p  # PNG previews

# Rebuild the district GLB so parked cars pick up the new meshes.
python3 -m cityview city --place harmonie
```
